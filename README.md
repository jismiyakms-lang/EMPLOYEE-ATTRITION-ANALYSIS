Power BI – Employee Attrition Analysis

📌 Project Overview

This project focuses on analyzing employee attrition using Power BI. The interactive dashboard helps identify patterns and factors associated with employee turnover and supports data-driven HR decisions.

📊 Dataset Information

* Total Employees: 5,000
* Total Columns: 29
* Missing Values: 0
* Key Features: Salary, Job Role, Promotions, Burnout, Work Mode, and Employee Details.

🛠️ Tools & Technologies

* Microsoft Power BI
* Data Analysis
* Data Visualization
* Interactive Dashboards

📈 Dashboard Features

KPI Cards

* Total Employees
* Attrition Rate
* Average Salary Hike
* Average Working Years

Charts & Visualizations

1. Attrition Rate and Total Employees by Salary Hike – Stacked Area Chart.
2. Attrition Rate by Years of Experience – Clustered Column Chart.
3. Attrition Rate by Burnout Band – Clustered Bar Chart.
4. Employee Attrition by AI Tool Usage – Clustered Column Chart.
5. Attrition Rate by Job Role – Clustered Column Chart.

Interactive Slicers

* Department
* Work Mode
* Overtime Hours per Week
* Performance Rating

🎯 Project Objectives

* Analyze employee attrition patterns.
* Identify factors associated with employee turnover.
* Explore attrition across different employee categories.
* Provide meaningful HR insights.
* Support better employee retention strategies.

💡 Key Takeaway

The interactive Power BI dashboard provides insights into employee attrition and helps HR teams make informed decisions to improve employee retention.
